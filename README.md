# Caso fictício: geladeira com vício não reparado 

  

## Finalidade 

Projeto individual da disciplina: demonstrar fluxo de sanitização, RAG 

manual, verificação, auditoria, revisão humana e versionamento. 

Caso e dados 100% fictícios. 

  

## Estrutura 

entrada/ (relato bruto) · apoio/ (caso sanitizado e fontes) · 

docs/ (limites, especificação, prompts) · evidencias/ · entrega/ 

  

## Como usar / reproduzir 

1. Ler docs/limites_e_sigilo.md e docs/especificacao.md. 

2. Rodar docs/prompts/consulta_rag.md com os arquivos de apoio/. 

3. Verificar, auditar em conversa nova e registrar a revisão humana. 

4. Ler entrega/orientacao_inicial.md. 

  

## Aviso 

Não avalia correção jurídica material. Não substitui advogado.
